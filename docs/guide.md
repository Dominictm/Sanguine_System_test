## 1. Запуск и первый старт

**Двойной клик на `start.bat`** — единственное, что нужно сделать.

Скрипт автоматически:
- Проверяет наличие Node.js и Git, при необходимости устанавливает
- Запускает TgWsProxy (если есть в корне — нужен для Gemini AI)
- Ставит npm-зависимости при первом запуске
- Открывает браузер на `http://localhost:4295`

Окно терминала держи открытым — закрытие останавливает сервер.
Для перезапуска сервера без закрытия окна: **Инструменты → 🔌 Подключение AI → Перезапустить сервер**.

### Первоначальная настройка

1. **Создай город** — раздел **Города** в левой панели, кнопка-спойлер **+ Создать новый домен** внизу страницы (см. [раздел 3](#3-города-домены)).

2. **Настрой ИИ** (опционально) — **Инструменты → 🔌 Подключение AI** (ключи/OAuth провайдеров) и **⚡ Назначение генераций** (какой провайдер и модель используются для каждой функции).
   Без ИИ-провайдера интерфейс работает полностью, только генерация недоступна.

3. **Добавь персонажей** — через кнопку **+ Новый персонаж** на странице «Персонажи» или вручную (папка `cities/<город>/characters/`).

## 2. Интерфейс

### Структура

```
┌─────────────┬──────────────────────────────────────────┐
│  Sidebar    │  Основная область                        │
│             │                                          │
│  🩸 Logo    │  Контент текущего раздела                │
│  🏙 Город  │                                          │
│             │                                          │
│  Навигация  │                                          │
│             │                                          │
│  Париж,2010 │                                          │
└─────────────┴──────────────────────────────────────────┘
```

Разделы в левой панели сверху вниз: Панель, Хронология, Персонажи, Связи, Фракции, Локации, Сессия, Хроники, Модули, Нити, Слухи, Звуковая библиотека, Библиотека, Инструменты, Города, Поиск.

Поверх всего интерфейса, в правом нижнем углу, — плавающая кнопка **🎲 Бросок** ([раздел 8](#8-бросок-кубиков)): доступна на любой странице.

### Переключение города

В покое поле под логотипом показывает просто название города и год (например, «Париж, 2010»). При наведении курсора оно превращается в выпадающий список со всеми созданными городами — выбор сразу переключает все данные: персонажей, хроники, события, локации. Кнопка **+** рядом — быстрый переход к созданию нового домена.

### Свёрнутая боковая панель

Маленькая кнопка-треугольник под кнопкой тура (**?**) сворачивает левую панель в узкую полосу с одними только значками разделов — название проекта и подписи прячутся, остаётся капля 🩸 и та же кнопка (теперь развернуть обратно). Наведение на значок показывает всплывающую подсказку с названием раздела. Состояние (свёрнуто/развёрнуто) запоминается между заходами.

### Тур по интерфейсу

Кнопка **?** рядом с логотипом запускает интерактивный тур по всем разделам.

## 3. Города (домены)

Каждый город — самостоятельная единица. Можно вести несколько городов одновременно.

### Раздел «Города»

Открывает сетку карточек всех существующих городов (название, год, число персонажей/модулей/локаций; текущий выбранный город помечен бейджем «Активен»). Клик по карточке открывает детальный просмотр города. Если городов ещё нет — подсказка создать первый ниже.

### Создание города

Разверни спойлер **+ Создать новый домен** внизу страницы «Города». Форма читается как воронка «кто → о чём говорим → как звучим → техническая тонкая настройка»:

- **Город \*** — русскоязычное имя (например, «Берлин»); папка `cities/<slug>/` создаётся автотранслитерацией названия — превью слага показывается тут же
- **Год \*** — игровой год сеттинга (например, 2010)
- **Сеттинг** — общее описание: эпоха, тон, в рамках какого канона разворачиваются сцены
- **Фракции** — пять групп: **Секты** и **Независимые кланы** — чипы, добавляются кнопкой 📚 из библиотеки «Сородичи» (клик по чипу убирает фракцию); **Другие фракции**, **Фракции смертных** и **Государственные фракции** — списки свободным текстом (по строке на фракцию), для двух последних тоже доступна кнопка 📚 с подбором из библиотеки «Смертные» (соответственно религиозные/криминал/гражданские организации и правительственные службы). Список сект и кланов из этого поля становится источником для дропдауна «Влияние» в блоке «Район» после создания города (см. ниже)
- **Голос и стиль хроники** — Лейтмотивы и атмосфера / Специфика ответа / Чего избегать / Источники: то, что формирует голос Рассказчика для этого города, видно сразу, без спойлера
- **▸ Правила и ограничения города** (свёрнуто) — 7 полей тонкой настройки: Охотничьи угодья, Законы домена, Смертные институции, Календарь города, Технологии и Маскарад, Ограничения генерации, Именник и фактура

**Районов в этой форме больше нет** (изменение 2026-08-04): раньше был текстовый список через запятую, теперь районы заводятся уже ПОСЛЕ создания города — кнопкой **+ Добавить район** на вкладке «География» просмотра города (см. ниже), каждый со своей карточкой (тип/секта/описание), без фантомной обёртки папок — просто `locations/<slug-района>/`.

Политический ландшафт, ключевые локации и значимые места в форме создания тоже не запрашиваются — их обычно ещё не с чем заполнять на старте; они добавляются позже, через просмотр/редактирование уже созданного города (см. ниже).

После создания город появится и в сетке карточек, и в выпадающем списке слева.

### Просмотр города

Клик по карточке города открывает детальный просмотр с четырьмя вкладками:

- **Общая** — название/год, Сеттинг, Законы домена, Календарь города, Технологии и Маскарад, Голос и стиль хроники (те же 4 поля, что в форме создания), плюс свёрнутый блок **«Правила и ограничения города»** с оставшимися техническими полями.
- **Политика** — «Властители города» и «Примогенат» как таблицы ключ-значение (роль → персонаж), плюс текст «Политический ландшафт».
- **Фракции** — статичные метки-чипы по группам: Секты, Независимые кланы, Другие фракции. Пустые группы скрыты.
- **География** — кнопка **+ Добавить район** (название, тип, секта, описание) и карточки уже созданных районов (спойлеры, разворачиваются по клику; у каждого — локации внутри, с возможностью привязать существующую локацию к району или открепить её обратно в общий район «Другие» — перенос физический, папка локации переезжает на диске, поэтому оба действия требуют подтверждения), «Значимые места» (редактируемый список: название + описание, кнопки «+ Добавить запись»/✕ на строку и общее «✓ Сохранить»), Ключевые локации, Охотничьи угодья.

Редактирование самих полей (кроме «Значимых мест», которые правятся прямо на вкладке) — через кнопку «Редактировать» карточки города, тем же набором полей, что и при создании, плюс восстановленный доступ к Политическому ландшафту/Географии/Ключевым локациям.

### Персонаж из другого города

Если персонаж гостит в чужом городе: **Инструменты → Учёт данных → 🌍 Кросс-город**.
Данные пишутся в `cities/<город>/archive/visitors.md` — один источник истины без копий карточки.

## 4. Персонажи

### Просмотр

Раздел **Персонажи** показывает карточки всех персонажей города.

**Фильтры:**
- Поиск по имени (в реальном времени)
- По линейке: Вампиры / Феи / Смертные / Оборотни / Маги / Охотники
- По статусу: Активен / Летаргия / Мёртв / Пропал / Неизвестен
- По принадлежности (вкладки над сеткой): Все / 🎬 Мастера / 🎲 Игроки / 🎭 Эпизодические / 🐾 Фамильяры

Карточки с несколькими изображениями автоматически листают арт каждые 12–50 секунд.

### Создание персонажа

Кнопка **+ Новый персонаж**:

1. Выбери линейку WoD и принадлежность (Персонаж мастера / Персонаж игрока / Эпизодический персонаж / Фамильяр)
2. Заполни поля: имя (кириллица), клан, фракция, поколение, год рождения / Объятия, Сир (для вампиров); Обличье, Двор, Дом (для фей)
3. Биография, внешность (3–5 визуальных маркеров)
4. Загрузи арт (опционально)

Персонаж создаётся с правильной структурой папок и обновляет `characters_index.md`.

### Карточка персонажа (детальный вид)

Клик по персонажу открывает панель с вкладками:

#### Вкладка «Информация»
Основные данные из карточки: клан, фракция, статус, поколение, связи. Фон подкрашивается цветом клана. Поля редактируются на месте (кнопка ✏), для части полей рядом — кнопка **📚**, открывающая подбор значения из соответствующей библиотеки вместо ручного ввода:

- **Клан/Раса**, **Секта** — автодополнение по библиотеке «Сородичи» (для смертных/охотников «Секта» — одиночный выбор через 📚 из религиозных организаций)
- **Титул** (для не-фей; у фей вместо этого «Иерархия» — обычное текстовое поле) — подбор из библиотеки «Титулы», сначала показывает варианты по секте/клану персонажа, затем полный список; можно выбрать несколько
- **Дисциплины** — подбор из библиотеки «Дисциплины», сначала клановые, затем все остальные; можно выбрать несколько, поле по-прежнему принимает и свободный текст
- Только для **смертных и охотников** — дополнительно **Организация** (подбор по 3 категориям библиотеки «Смертные»: религиозные, криминал, гражданские), **Должность** (подбор из библиотеки, показывается, когда заполнена «Организация») и **Роль в секте** (свободный текст, показывается, когда заполнена «Секта»)

#### Вкладка «Биография»
Полный текст биографии с редактором. Кнопка **✍️ Сгенерировать ИИ** — сгенерировать описание по полям карточки.

#### Вкладка «Отношения»
Список связей с другими персонажами. У каждой связи — цель, короткий структурированный **вид отношений** и необязательное развёрнутое описание.

**Редактирование** — у каждой строки:
- **Имя** — с подсказкой-автодополнением по уже заведённым персонажам, можно вписать и своё
- **Вид отношений** — короткое слово/фраза; кнопка **📚** открывает библиотеку видов связи (базовый набор — Сир, Чайлд, Брат, Сестра, Гуль, Домитор, Фамильяр, Союзник, Враг, Семья, Тайная связь — плюс авторские, добавленные ранее) или впиши свой текст прямо в поле
- **Взаимно** — чекбокс: при сохранении такая связь автоматически зеркалируется на карточку цели (тем же видом отношений и пустым описанием, если своё не задано); правка или удаление связи на одной стороне обновляет и вторую. Для части видов отношений — **Сир ↔ Чайлд**, **Домитор ↔ Гуль**, **Брат/Сестра** (зеркальный вид подбирается по полю «Пол» цели) — чекбокс включается сам и вид отношений на другой стороне подставляется автоматически, не совпадая буквально с исходным
- **Развёрнутое описание** — необязательное; при заданном виде отношений это пояснение к нему («доверенное лицо, помогает в делах»), а не альтернативный вид

Новые виды отношений, которых ещё нет в библиотеке, можно завести на месте — просто вписав своё слово в поле — либо превратить в постоянные позже через модалку **«Управление связями»** на графе ([раздел 16](#16-граф-связей)). «Фамильяр» дополнительно открывает на карточке персонажа отдельную вкладку «Фамильяр» (см. ниже) и красится своим цветом на графе «Связи».

#### Вкладка «Дневники»
Список дневниковых записей по периодам (формат `ГГГГ-ММ` или `retrospective`).

- Клик по периоду — открывает запись
- **✍️ Сгенерировать ИИ** — генерирует литературную запись по полям (период, заголовок сессии, подсказка-настроение)
- Запись редактируется перед сохранением
- Удаление — кнопка корзины

#### Вкладка «Лист V20»
Полный игровой лист персонажа: атрибуты, навыки, дисциплины, добродетели, здоровье, воля, кровь, фоны, преимущества/недостатки.

- **📋 Сгенерировать лист** — ИИ заполняет числа по карточке и биографии
- **♻ Перегенерировать ИИ** — перезаписать числа из нового ИИ-запроса
- Все поля редактируются вручную, изменения сохраняются автоматически
- Блок Человечность/Путь: сверху редактируемое название (если Путь не задан — плейсхолдер «Человечность»), под ним — точки значения
- Временная Воля и Запас крови (кроме 3-го поколения) — квадратные боксы: клик по N-му боксу заполняет все от первого до N-го разом, повторный клик по последнему заполненному снимает его на единицу (как и точки атрибутов, доступно и с клавиатуры)
- Клик по дисциплине — открывает справочник с описанием уровней

#### Вкладка «Фамильяр»
Появляется, только если среди связей персонажа есть запись с видом отношений или описанием, содержащим слово «фамильяр» (например, вид отношений «Фамильяр»). Показывает компактную карточку фамильяра (портрет, линейка, статус, ключевые поля) и кнопку **«Открыть карточку целиком»**. Если персонаж с указанным именем не найден в общем реестре — вкладка подсказывает завести для фамильяра отдельную карточку с принадлежностью «Фамильяр».

#### Вкладка «Описание»
Вся карточка персонажа в raw-виде с редактором. Полный контроль над markdown.

#### Блок «💬 Реплики НПС»
Генерирует реплики в характере персонажа для заданной ситуации.
Голос, клановый стиль и факты берутся из карточки — никаких выдуманных деталей.

## 5. Хроники

**Хроники** — раздел для управления сюжетными арками.

### Список хроник

Карточки всех хроник города с количеством модулей. Кнопка **+ Хроника** создаёт новую.

### Детальный вид хроники

Три вкладки: **📖 Модули** (список сессий), **📅 События** (лента событий) и **📝 Описание** (настроение хроники + свободный текст о том, о чём она — с кнопкой **✏ Редактировать**, изменения сохраняются кнопкой «Сохранить»/откатываются «Отмена»).

Под названием хроники — строка кнопок управления:

| Кнопка | Что делает |
|--------|------------|
| **📕 Книга** | Собирает всю хронику в самодостаточный HTML-документ (печать → PDF) |
| **🕰️ В хронологию** | Добавляет итог хроники в хронологию мира города |
| **🎭 Директор** | ИИ анализирует текущее состояние и предлагает варианты следующей сцены |
| **+ Модуль** | Создаёт новый модуль внутри хроники (кнопка видна на вкладке «Модули») |

На вкладке «События» дополнительно появляется поле периода и кнопка **📺 Ранее в хронике…** (генерирует recap последних событий для зачитывания игрокам).

> Отдельная страница **Модули** в левой панели показывает тот же список модулей, но сразу по всем хроникам города — удобно, когда не хочешь заходить в конкретную хронику.

## 6. Модули и сессии

Модуль = одна история (может занимать несколько игровых вечеров). Жизненный цикл — три фазы.

### Фаза A — Подготовка

1. В хронике нажми **+ Модуль**
2. Заполни название и раздел `## 💡 Концепция` в модуле
3. Открой модуль → кнопка **🪄 Сгенерировать**

**Форма генерации сценария:**
- Список персонажей-игроков (ПК)
- Список НПС, задействованных в модуле
- Текст концепции → ИИ пишет полный `scenario.md`

ИИ учитывает: текущие статусы персонажей, открытые нити, даты в таймлайне — и предупреждает о противоречиях.

### Фаза B — Ведение игры

Играть сценарий сцена за сценой удобнее всего на отдельном экране **Сессия** — см. [раздел 7](#7-сессия-живой-режим-игры).

**Быстрая запись после сессии** (без прозы, просто факты) — на странице модуля, вкладка **🎲 Сессии**: дата, статус, сыгранные сцены (текстом, через запятую), заметки — кнопка **«Добавить запись»** дописывает запись в лог модуля. Рядом — кнопка **🔍 Проверить канон**, сверяющая введённый текст с фактами карточек (статусы персонажей, даты). Уже записанные сессии можно отредактировать (✏️) или удалить (🗑, с подтверждением) прямо в списке — номера оставшихся записей пересчитываются автоматически. Экран **Сессия** ([раздел 7](#7-сессия-живой-режим-игры)) собирает и предзаполняет эту же форму заметками, сделанными по ходу игры кнопкой «→ Записать сессию» — вводить всё заново не нужно.

## 7. Сессия (живой режим игры)

Раздел **Сессия** — экран для вождения игры «за столом»: сценарий по сценам, участники, музыка и заметки в одном месте, без переключения между вкладками.

### Выбор модуля

Одна строка сверху: выпадающий список хроник (скрытые хроники помечены 📂, закрытые — подписью «(закрыта)»), рядом с ним — список модулей выбранной хроники. Последние выбранные хроника, модуль и сцена запоминаются и восстанавливаются при следующем заходе на страницу.

Если в хронике ещё нет модулей — подсказка создать первый на странице «Модули».

### Сценарий по сценам

Сценарий модуля разбивается по `##`-заголовкам markdown-файла на раскрывающиеся блоки-сцены. Заголовок сцены кликабелен — раскрывает её текст (остальные сцены сворачиваются). Панель **← / N из M / →** для перехода между сценами закреплена по нижнему краю рабочей области — остаётся на виду, даже когда текст сценария прокручен далеко вниз; появляется только когда выбраны и хроника, и модуль, и в нём есть сценарий, стрелки отключаются на первой/последней сцене.

### Боковая панель

Остаётся на экране при прокрутке длинного сценария (на мобильной ширине — обычная раскладка без прилипания). Содержит:

- **👥 Персонажи модуля** — чипы ПК и НПС из карточки модуля; если персонаж есть в общем реестре, чип кликабелен и открывает его карточку
- **🎵 Аудио-пресеты** — выпадающий список пресетов из звуковой библиотеки ([раздел 14](#14-звуковая-библиотека)); пресеты, привязанные к локациям модуля, поднимаются в начало списка и помечены 📍; кнопка ▶/⏹ рядом со списком запускает/останавливает выбранный пресет прямо отсюда (запуск нового сам останавливает предыдущий)
- **Заметка сцены** — заметка к текущей сцене на **текущую** игровую сессию (номер считается автоматически — сколько сессий уже записано в модуле, плюс одна). Если сцена уже игралась в прошлой сессии — её прежняя заметка показывается сверху как история только для чтения, с пометкой «Сессия N», а поле ввода ниже всегда начинается пустым для новой записи. Ничего не перезаписывается — заметки разных сессий по одной сцене хранятся отдельно
- **📝 Заметки сессии** — общая заметка по всему модулю (тоже сохраняется в файл модуля, не теряется при закрытии вкладки)

### «→ Записать сессию»

Собирает заметки сцен **текущей** сессии (записи из прошлых сессий уже вошли в свои более ранние логи и повторно не подставляются), подставляет их текст и список сцен в форму на вкладке **🎲 Сессии** страницы модуля — остаётся проверить и нажать «Добавить запись». Уже заполненные вручную поля формы не затираются. Заметки, оставленные на неформальных блоках сценария (Вступление, GM-справка и т.п., а не на «Сцена N»), тоже подставляются — отдельным блоком «Прочее» в конце текста.

## 8. Бросок кубиков

Круглая кнопка **🎲** зафиксирована в правом нижнем углу экрана на любой странице — не нужно уходить со сцены ради броска.

### Панель броска

Клик открывает панель «🎲 Бросок V20» с полями:
- **Персонаж** — необязательно; без выбора атрибуты и способности показывают полный список названий (без чисел), пул кубиков вводится вручную
- **Атрибут** и **Способность** — при выбранном персонаже (или уже открытом его листе V20) списки показывают только реально прокачанные (>0) значения с цифрой в скобках и автоматически суммируются в пул. Внизу списка способностей всегда доступна опция **«Не владеет»** — она даёт 0 к пулу и добавляет +2 к введённой сложности (однократно, повторное переключение не накапливает штраф; рядом с полем сложности при этом появляется поясняющий бейдж)
- **Добродетель** — Совесть/Решимость, Самоконтроль/Инстинкты, Смелость или Сила воли; выбор перезаписывает пул её значением целиком, не складывая с атрибутом/способностью
- **Пул** и **Сложность** — редактируются вручную в любой момент

### Результат

Кнопка **«Бросить»** кидает пул кубиков d10 по правилам V20: успех — кубик ≥ сложности, десятки «взрываются» (дают дополнительный бросок), единицы вычитают успехи; если чистых успехов 0 и есть хотя бы одна единица — ботч. Кубики отображаются чипами (десятки/хиты и единицы подсвечены отдельно, перебросы помечены ↻), под ними — вердикт («N успех(ов)», «Провал» или «БОТЧ»). Ниже — история последних 10 бросков текущей вкладки браузера (не сохраняется между перезагрузками страницы).

> Отдельная модалка броска внутри листа персонажа (кнопка-кубик рядом с точками атрибута/способности на вкладке «Лист V20») — самостоятельный инструмент для точечного броска по конкретной характеристике листа, не связана с этой плавающей панелью.

## 10. Локации

**Локации** — карточки мест: злачные клубы, Элизиумы, логова, нейтральные территории.

На карточке в сетке — всегда видимая кнопка 🗑 (удаление с подтверждением) и компактные бейджи опасности (⚔️)/Маскарада (🎭), если эти уровни заданы; полная подпись — во всплывающей подсказке при наведении.

### Фильтры

- Поиск по названию
- **Статус**: 🏛️ Элизиум · 👑 Приёмная князя · 🛌 Убежище · ⚔️ Шериф · 📜 Сенешаль (или «Все статусы»)
- **Район**: автозаполнение из структуры папок
- **Уровень Маскарада**: 🟢 Низкий / 🟡 Средний / 🔴 Высокий

«Статус» и «Опасность» — независимые характеристики: первая описывает роль локации в городской политике, вторая — насколько рискованно там находиться; фильтр в списке есть только по «Статусу», «Опасность» смотрится в бейджах карточек и на вкладке VtM.

### Создание локации

Кнопка **+ Создать локацию** в разделе «Локации». Там же — экспорт (⇩) и импорт (⇧) локаций города JSON-файлом.

### Детальный вид локации

| Вкладка | Содержимое |
|---------|------------|
| **Метаданные** | Район, адрес, под чьим контролем |
| **Атмосфера** | Свободный текст общего впечатления от места (с кнопкой 🔄 регенерации) |
| **VtM** | Форма по полям — Статус, Фракция (или «Хозяин» + чекбокс «Частный домен» для локаций без формальной привязки к фракции), Постоянные фигуры, Угрозы, Маскарад, Опасность — плюс отдельное текстовое описание роли в местной политике |
| **Сенсорика** | Сенсорная палитра по каналам (Свет / Звук / Запах / Тактильное — можно добавить свои), с кнопкой 🔄 регенерации на канал; вкладка помечается ⚠️, пока не заполнен хотя бы один из обязательных каналов (Свет/Звук/Запах) |
| **Ключевые точки** | Важные места внутри локации — таблица «место / описание» |
| **Крючки** | Сюжетные зацепки для Рассказчика (с кнопкой 🔄) |
| **🖼 Изображения** | Галерея арта локации |

Статус, уровень опасности и Маскарад дополнительно вынесены бейджами в шапку карточки (под названием), не только на вкладку VtM.

> Аудио-пресеты можно привязать к локации в звуковой библиотеке ([раздел 14](#14-звуковая-библиотека)) — тогда на экране «Сессия» такой пресет сам поднимется наверх списка, когда в модуле фигурирует эта локация.

### Факты биографии

Готовые пункты биографии по категориям (Общие / Вампиры / Гули и ревенанты / Маги / Подменыши) — можно подставить в лист персонажа кнопкой «+ Из справочника», не сочиняя формулировку с нуля.

## 16. Граф связей

Раздел **Связи** — интерактивный граф всех отношений в городе.

### Управление

- **Перетаскивание** — перемещение узлов
- **Колесо мыши / жест** — масштабирование (отдельных кнопок «+»/«−» нет)
- **Клик по узлу** — панель с деталями персонажа (портрет, клан, связи)
- **↺** — сбросить масштаб и оба фильтра разом
- **+** (рядом с ↺) — открывает модалку **«Управление связями»** (см. ниже)

### Фильтры

Две строки чипов-чекбоксов над графом: **по линейке** сверху (только реально присутствующие в городе) и **по типу связи** снизу (только реально присутствующие среди рёбер графа — список динамический, отражает то, что реально встречается в картах персонажей на данный момент). Ребро видно, только если отмечены обе линейки на его концах И его тип связи — фильтры работают совместно, не по отдельности.

### Условные обозначения

**Цвет узла** — линейка:
`🔴 Вампир` · `🟣 Фея` · `⚫ Смертный` · `🟤 Оборотень` · `🔵 Маг` · `🟠 Охотник`

**Обводка узла** — статус:
`красная = Активен` · `синяя = Летаргия` · `серая = Мёртв`

**Цвет связи** — тип отношения; у каждого чекбокса в нижней строке фильтров, в конце подписи, — цветной кружок того же цвета, что и рёбра этого типа на графе. Для видов отношений из библиотеки (включая авторские) цвет берётся из самой библиотеки — новым видам при создании назначается случайный цвет автоматически; для легаси-связей без совпадения с библиотекой действует старый фиксированный набор (Семья, Сир/Чайлд, Фамильяр, Союзник, Враг, Преданность, Романтика, Подозрение, Знакомый, Тайная связь, Нейтральный).

### Управление связями

Модалка (кнопка **+** рядом со сбросом графа) — редактор библиотеки видов отношений, две колонки:

- **Постоянные связи** — сам список библиотеки (`system/library/relation-types.json`), тот же, что предлагает кнопка 📚 на вкладке «Отношения» карточки персонажа. Поиск, добавление новой записи по имени (цвет генерируется случайно), переименование ✏ и удаление 🗑 — только для авторских записей, базовые 11 видов защищены от правки.
- **Авторские связи** — агрегированный список видов отношений, которые уже встречаются в картах персонажей города, но ещё не заведены в библиотеке (включая своё слово, вписанное прямо в поле «Вид отношений» на карточке). Кнопка **«Сделать постоянной»** у любой строки переносит её в «Постоянные связи» — карточки персонажей при этом не переписываются, дальнейшие правки этого вида просто попадают в общую библиотеку.

## 17. ИИ-генерация

### Настройка провайдеров

**Инструменты → ⚡ Назначение генераций**

Каждая функция генерации настраивается независимо:

| Функция | Описание |
|---------|----------|
| **Внешность по арту** | Vision-анализ загруженного изображения |
| **Генерация локаций** | Карточки мест (атмосфера, VtM-контекст, крючки) |
| **Генерация прозы** | Дневники и финалы сессий |
| **Биография** | Текст биографии персонажа |
| **Реплики НПС** | Диалог в характере |
| **Лист V20** | Числа атрибутов/навыков по карточке |
| **Сценарий модуля** | Полный сценарий по концепции |

Для каждой функции выбираешь: **провайдер** (OpenRouter / GPT / Claude / Gemini) и **модель**.

### Доступные провайдеры

| Провайдер | Авторизация | Где настроить |
|-----------|-------------|---------------|
| **Claude** | Кнопка «Войти через Claude» или `ANTHROPIC_API_KEY` | Инструменты → 🔌 Подключение AI |
| **Gemini** | `GEMINI_API_KEY` + TgWsProxy | [docs/gemini.md](gemini.md) |
| **OpenRouter** | `OPENROUTER_API_KEY` | Инструменты → 🔌 Подключение AI |
| **GPT** | `OPENAI_API_KEY` | Инструменты → 🔌 Подключение AI |

### Резервный провайдер

При перегрузке (ошибка 429) генерация автоматически переключается по цепочке:
`Claude → GPT → OpenRouter`. В ответе появляется пометка «⚠️ сгенерировано резервным».

### Функции генерации по разделам

#### Проза дневника (карточка персонажа → Дневники)
Кнопка **✍️ Сгенерировать ИИ**. Поля:
- Период `ГГГГ-ММ`
- Заголовок сессии (контекст)
- Подсказка-настроение

Результат — редактируемый черновик перед сохранением.

#### Реплики НПС (карточка персонажа)
Блок **💬 Реплики НПС** → введи ситуацию → несколько реплик в характере, голосе и клановом стиле.

#### Лист V20 (карточка → вкладка «Лист V20»)
**📋 Сгенерировать лист** — ИИ назначает числа атрибутам, навыкам, дисциплинам по карточке и биографии.
**♻ Перегенерировать** — пересчитать числа (существующие перезапишутся).

#### Сценарий модуля (страница модуля)
**🪄 Сгенерировать** → форма с ПК, НПС и концепцией → полный `scenario.md`.
ИИ проверяет таймлайн и статусы персонажей. Предупреждения о противоречиях выводятся отдельно.

#### AI-Директор (хроника)
**🎭 Директор** — анализирует состояние модуля и предлагает 3–5 вариантов следующей сцены с учётом напряжённости и открытых нитей.

#### Recap (хроника)
**📺 Ранее в хронике…** — генерирует «ранее в нашей хронике» для зачитывания игрокам в начале сессии.

## 20. Панель целостности

Раздел **Панель** содержит блок **Целостность данных** (разворачивается по клику).

### Проверки

- **Битые ссылки** — ссылки в markdown-файлах на несуществующие файлы
- **Сироты** — файлы персонажей/локаций без записи в индексах
- **Дубликаты слагов** — два персонажа с одинаковым `Слаг`
- **Неполные карточки** — отсутствуют обязательные поля

До 40 проблем каждого типа с кнопкой «Показать ещё».

### Проверка канона

Поле «Вставь текст сцены» → ИИ сверяет с фактами из карточек:
- Живы ли персонажи в сцене (статус «Мёртв» / «Летаргия»)
- Соответствуют ли даты состоянию персонажей
- Нет ли фактических противоречий с карточками

## Советы Рассказчику

**Воркфлоу сессии:**

```
До игры:
  Хроники → открытая хроника → + Модуль → заполни концепцию → 🪄 Сгенерировать
  Звуковая библиотека → собери пресеты под ключевые локации модуля

Во время игры:
  Сессия → выбери хронику и модуль → веди по сценам,
  держи под рукой заметку сцены и плавающую кнопку 🎲

После игры:
  Сессия → «→ Записать сессию» (или сразу вкладка «Сессии» модуля) → заполни лог → Добавить запись
  Карточки персонажей → Дневники → ✍️ Сгенерировать ИИ

По завершении:
  Страница модуля → 🔒 Закрыть модуль
```

**Нити — твой дашборд незакрытых дел.** Открывай раздел Нити в начале каждой сессии — что тлеет, что горит. Клик по нити с Панели сразу приводит к нужной карточке.

**Граф связей** полезен перед модулем с политическими интригами — видно кто кому обязан и где могут возникнуть неожиданные союзы. Фильтруй по типу связи, чтобы увидеть только вражду или только тайные связи.

**ИИ-реплики НПС** во время сессии — открой карточку персонажа на телефоне, введи ситуацию и читай ответ голосом НПС.
