# Приват-доцент

- **Принадлежность:** Ассамиты (клан)
- **Источник:** https://wod.fandom.com/ru/wiki/Приват-доцент

## Описание

Приват-доцент доказал, что обладает достаточной увлечённостью и сосредоточенностью для достижения уровня, соответствующего у смертных докторской степени. Магу крови для этого нужно как следует овладеть первичным путём Тауматургии (и не менее чем двумя его ритуалами четвёртого уровня), а учёному другого профиля — набрать знания, достаточные для успешной сдачи университетских экзаменов по избранной старейшинами специализации.
