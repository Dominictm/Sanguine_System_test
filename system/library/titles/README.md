# Библиотека титулов V20

Канонический источник справочника титулов: **по одному MD-файлу на титул**.
Сервер (`web/lib/titles.js` → `parseTitleMd`) парсит эти файлы, отдаёт по
`GET /api/library/titles`, веб рендерит (вкладка «Сородичи» → «Титулы»).

Формат — зеркало `clans/README.md`/`sects/README.md`, с двумя отличиями:
поле «Принадлежность» (свободный текст — не всегда секта, у части титулов
это клан или смертный род) вместо «Секта», и опциональный boolean-флаг
«Негативный» (строка присутствует только если титул негативный).

## Формат файла

```markdown
# Князь

- **Принадлежность:** Камарилья
- **Негативный:** да                ← только если титул негативный
- **Источник:** https://wod.fandom.com/ru/wiki/...

> (опц.) короткая цитата-эпиграф

## Описание

<текст — своими словами, не копипаста>
```
