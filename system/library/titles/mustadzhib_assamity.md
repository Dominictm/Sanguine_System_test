# Мустаджиб

- **Принадлежность:** Ассамиты (клан)
- **Источник:** https://wod.fandom.com/ru/wiki/Мустаджиб
> Не путать с одноимённым званием Чёрной Руки Шабаша — оба происходят из одной культурной традиции, но применяются в разных структурах.

## Описание

Мустаджиб («достойный») — звание недавно обращённого воина-рафика внутри клана: прежде чем ему разрешат действовать самостоятельно, он должен доказать свою пользу. По одной версии традиции, мустаджибом становится любой, кто пережил первый бой после Становления, и служит своему сиру семь лет без права на ошибку, прежде чем получить следующее звание — фидаи.
