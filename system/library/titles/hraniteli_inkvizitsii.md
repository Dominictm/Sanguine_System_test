# Хранители Инквизиции

- **Принадлежность:** Шабаш · Инквизиция
- **Источник:** https://wod.fandom.com/ru/wiki/Хранители_Инквизиции

## Описание

Хранители — обычно отставные судьи-инквизиторы, курирующие полевых агентов Инквизиции Шабаша из крепости Санто Официо («Святая Палата»). Помимо общего надзора за расследованиями, в их обязанности входит следить, чтобы сами инквизиторы, постоянно имеющие дело со скверной, не поддались инфернальной порче.
