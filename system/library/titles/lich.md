# Лич

- **Принадлежность:** Тал'махе'Ра
- **Источник:** https://wod.fandom.com/ru/wiki/Лич
> ⚠️ Источник, указанный в вики-индексе титулов, описывает магов-личей (Mage: the Ascension) — понятие, не совпадающее с вампирскими титулами. Судя по одному лишь названию и принадлежности к Тал'махе'Ра, речь может идти о старейшине секты, чья личность или прежнее имя давно и намеренно стёрты из памяти каинитов, — но подтверждённого источника по вампирскому титулу с таким названием нет.

## Описание

⚠️ Требуется уточнение — доступный источник описывает не вампирский титул, а отдельное понятие из другой линейки Мира Тьмы (магов-личей). Достоверных сведений о значении этого титула внутри Тал'махе'Ра на данный момент нет.
