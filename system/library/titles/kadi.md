# Кади

- **Принадлежность:** Аширра
- **Источник:** https://wod.fandom.com/ru/wiki/Кади

## Описание

Кади — судья в рамках исламского права, изучающий законы Корана и прецеденты, накопленные поколениями предшественников. Почти в каждой умме Аширры есть собственный вампир-кади, обычно бывший правоведом ещё при жизни; он советует имаму и султану в правовых спорах и определяет должное наказание для нарушителей закона.

Возможности кади ограничены исключительно его личными ресурсами и поддержкой сообщества: действуя с благословения могущественных старейшин, судья обладает немалой властью, но, бросая вызов султану или имаму напрямую, должен взвешивать каждое слово.
