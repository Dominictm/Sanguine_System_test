# Внутренний Круг

- **Принадлежность:** Камарилья
- **Источник:** https://wod.fandom.com/ru/wiki/Внутренний_Круг

## Описание

Внутренний Круг — тайный совет, вокруг которого фактически вращается вся Камарилья, хотя формально о его существовании известно только по слухам. Раз в тринадцать лет старейшие представители кланов секты собираются в Венеции, чтобы определить политику Камарильи на следующий цикл и назначить (или сместить) юстициаров.

Кто именно входит в Круг — один из главных секретов секты; известно лишь, что это, предположительно, древнейшие представители своих кланов, добившиеся выживания и огромной силы. Между собраниями Круг, по слухам, продолжает направлять юстициаров и решать судьбы самых опасных врагов Камарильи — вплоть до внесения имени в Красный список, что равносильно вечной Кровавой Охоте.
