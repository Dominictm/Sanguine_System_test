# Мулла

- **Принадлежность:** Аширра
- **Источник:** https://wod.fandom.com/ru/wiki/Мулла

## Описание

Муллами называют самых уважаемых учёных мужей Аширры. В принципе, любой сородич секты способен посвятить себя изучению священных текстов, но сам титул муллы зарабатывается только долгими годами усердной учёбы и признанием со стороны тех, кто уже его носит. По всей исламской диаспоре каинитов этим титулом обладает лишь горстка вампиров — в их числе самые могущественные фигуры Аширры, включая её легендарного основателя.
